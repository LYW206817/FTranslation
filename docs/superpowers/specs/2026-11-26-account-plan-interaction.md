# 账号与套餐页交互

账号页的「看套餐与价格」进入套餐页并定位到价格区。首次显示时选择当前付费档，免费用户默认选择 Pro，周期默认月付。用户在同一登录会话里选过的档位和周期随页面保留，换账号或重新登录后恢复默认。

点击订阅时固定当时的档位和周期，处理期间暂停更改两项选择。先核对是否有待处理订单，有则继续该订单，否则按已固定的选项创建。登录会话变化时终止旧会话的交互，避免跨账号续单。

两页共用用量读取状态。同一次正在进行的读取可由两个页面复用。没有有效结果时只显示读取状态或错误，成功后显示实际进度并清除旧错误。日额度行只在结果确认有日额度时显示。切换账号或套餐后，旧结果不能更新当前用量。设备列表在自己的卡片内单独刷新。

账号连接失败和请求超时要有可区分的提示，日志只记请求目标主机、端口和错误类别。会话失效沿用重新登录的提示。下一次账号请求使用当时的 Windows 代理设置，包含系统的自动检测、配置脚本和绕过列表。切换代理时允许已发出的请求结束，本机账号服务继续直连。
