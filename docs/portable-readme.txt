Fast Translation 1.2.2 — 划词翻译桌面工具
==========================================

【安装】
双击 FastTranslation-1.2.2-Setup.exe 安装,向导里可以改安装位置(默认装在当前用户目录)。
免管理员权限,桌面和开始菜单会创建「Fast Translation」快捷方式。
系统要求:Windows 10 1903+ / Windows 11(64 位)。运行时已内置,无需安装 .NET。
装过 1.0.x(MSI 版)的不用先卸载,安装程序会自动清掉旧版本再装。

【以后升级不用再找我要安装包】
程序自己检查更新:
- 启动后约 30 秒静默检查一次,之后每 6 小时一次;发现新版本会弹窗,点「立即更新」自动下载、安装并重启
- 也可以手动查:托盘图标右键「检查更新」,或设置页「系统 → 检查更新」
- 检查更新只读取一个公开的清单文件,不上传任何本机信息

【首次使用】
1. 启动后会弹出引导窗口,输入你的 Qwen-MT API Key(阿里云 DashScope 控制台获取,sk- 开头)
2. 点「测试连接」确认可用,点「完成」
3. Key 保存在本机(Windows DPAPI 加密),不会上传

【日常使用】
- 划词:在任意应用里选中文本 → 弹出小工具条 → 点「翻译」看结果,可复制 / 替换原文 / 插入译文
- 手动:打开主窗口直接输入翻译(Ctrl+Enter 快捷键)
- 热键:Ctrl+Alt+T 呼出主窗口
- 取词开关:主窗口右上角开关,或托盘图标菜单
- 关闭主窗口 = 缩到托盘,划词服务继续;真正退出走托盘菜单「退出」
- 托盘图标在资源管理器重启后会自动挂回,无需重启程序
- 外观:设置里可选「跟随系统 / 浅色 / 深色」,跟随系统即读 Windows 的应用主题,改完需重启程序生效

【截图翻译】
- 划词工具条现在是三颗:复制 / 翻译 / 截图翻译;也可以按 Ctrl+Alt+S,或走托盘菜单「截图翻译」
- 按下去之后屏幕变暗,按住左键拖一个框,松开就开始翻;Esc 或右键取消
- 几秒后弹出译图浮窗,可以「复制图片」「另存为…」,Esc 关闭
- 译文由阿里云 qwen-mt-image-2.0 生成,约 0.004 元一张(1 元约 250 张),计入你自己的 API Key
- 截图以 base64 直传翻译接口,不上传到任何图床,也不需要公网地址
- 目标语言跟随设置里的目标语言,和文字翻译一致
- 效果边界:网页、宽界面这类稀疏排版效果好;密集小字、多栏挤在一起的界面会错位(建议框小一点分开翻)

【卸载】
Windows 设置 → 应用 → 安装的应用 → Fast Translation → 卸载
(你的 API Key 与设置保留在 %LOCALAPPDATA%\FastTranslation,不随卸载删除)

【隐私】
选中的文本只发送给阿里云 DashScope 翻译接口;不收集任何数据,不写日志(FT_DEBUG=1 诊断除外)。
更新检查只下载一个 JSON 清单和安装包,不携带任何标识。
诊断日志也不记录选中文本、API Key 或剪贴板内容。

【已知限制】
- Windows 终端 / cmd / PowerShell 一律只取词、不写回(Ctrl+C 在终端是 SIGINT)
- 密码框不取词
- 万维网页面(Chromium)首次划词可能需重试一次,程序已内置 3 次探测
- 安装包未做代码签名,首次运行 Windows 会提示「未知发布者」,点「更多信息 → 仍要运行」
